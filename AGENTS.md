- Embedded tracks live in `src/lib/mkv/*` + `useEmbeddedTracks`: every direct file is sniffed by its bytes (MKV vs MP4, names lie); playback always starts natively; subtitles with the original audio use the side-reader (`subtitleReader.ts`), and only a different audio language hands the element to the MSE engine — all via the existing EGD-routed `video-proxy`, so episode start stays instant and no new edge function is needed.
