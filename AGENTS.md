- Embedded tracks live in `src/lib/mkv/*` + `useEmbeddedTracks`: every direct file is sniffed by its bytes (MKV vs MP4, names lie); playback always starts natively; subtitles with the original audio use the side-reader (`subtitleReader.ts`), and only a different audio language hands the element to the MSE engine — all via the existing EGD-routed `video-proxy`, so episode start stays instant and no new edge function is needed.
- Profile shop frames animate via CSS layers in `src/components/profile/AnimatedFrame.tsx` (effects stored as a comma string, "none" = still) and backdrops render through `BackdropMedia.tsx` (image or muted looping video with poster fallback) — keeps every frame/backdrop surface (profile, shop, admin preview) identical and compositor-cheap.
- Profile backdrop media: gallery uploads are stored as base64 chunks in Firebase `profileMedia/{id}` (items reference `rtdb:{id}`) and every backdrop video is persisted in Cache Storage via `src/lib/profileMediaStore.ts`; shop + customization are mirrored in localStorage — instant paint on return, public storage buckets are blocked.
