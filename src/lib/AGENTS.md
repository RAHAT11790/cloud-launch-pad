- Chat moderation rules (filters, links, ban times, commands, slow mode, CEO check) live only in `chatModeration.ts`; client-enforced since the RTDB is public.
- Sign-up/reset emails go only through EGD row `email-service` (Gmail API worker `cloudflare-workers/email-service.js`; the Supabase copy is the same code + Deno adapter, kept equal by a test) via `src/lib/emailService.ts` (also the admin email-domain/guest rule from `settings/loginAccess`, mirrored in the Worker, + login-first flag). Each request is one hashed, single-use ticket in Firebase `emailAuth/tickets`, HMAC-sealed over all fields and changed only by ETag-conditional writes (rate counters and final states are also shadowed in Worker memory), so edited/rolled-back records are refused and the code and the email button can each work once; accounts are written only after a verified code or claimed link. Limits/defaults live in the Worker `DEFAULTS`/`BOUNDS`, mirrored by `emailStats.ts` (a test keeps them equal).
- Premium-on reload is decided only by `premiumReload.ts` (inactive→active seen this visit); a page reload is the one reliable way to drop ad tags already injected.
- Player ads are released only by `AdsterraAdManager` (tap in the player) when `adPacing.ts` opens a slot; `releaseAd` in `adsterraAds.ts` falls back to the Direct Link when the tag is blocked or silent — one pacing place keeps the ad script alive all session.
- The selected download server is probed via `routeHealth` and skipped while dead (`applyActiveDownloadServer`); the download page tries active-server then the file's own server per file — an offline tunnel must never block healthy files.
