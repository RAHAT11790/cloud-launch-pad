- Chat moderation rules (filters, links, ban times, commands, slow mode, CEO check) live only in `chatModeration.ts`; client-enforced since the RTDB is public.
- Sign-up/reset emails go only through EGD row `email-service` (Gmail API worker `cloudflare-workers/email-service.js`; the Supabase copy is the same code + Deno adapter, kept equal by a test) via `src/lib/emailService.ts` (also the admin email-domain/guest rule from `settings/loginAccess`, mirrored in the Worker, + login-first flag). Each request is one hashed, single-use ticket in Firebase `emailAuth/tickets` changed only by ETag-conditional writes, so the code and the email button can each work once and using one kills the other; accounts are written only after a verified code or claimed link.
- Premium-on reload is decided only by `premiumReload.ts` (inactive→active seen this visit); a page reload is the one reliable way to drop ad tags already injected.
